# 📄 AI Resume Screening System

An AI-powered Resume Screening System that automatically analyzes resumes, extracts relevant information, and predicts suitable job categories using Natural Language Processing (NLP) and Machine Learning techniques.

## 📌 Project Overview

Recruiters often spend significant time manually reviewing hundreds of resumes. This project automates the initial screening process by analyzing resume text and classifying candidates based on their skills and job profiles.

The system uses NLP techniques to preprocess resume data, extract meaningful features, and apply machine learning models for automated resume classification.

* 🔍 Automated resume classification
